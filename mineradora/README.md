
# MINERADORA DE VÍDEOS VIRAIS

Sistema de descoberta e análise de vídeos populares internacionais.

## Objetivo

Encontrar vídeos reais que estão ganhando popularidade nos Estados Unidos e comparar sua presença no Brasil.

## Funcionamento

O sistema deverá:

1. Encontrar vídeos populares nos Estados Unidos.
2. Mostrar miniaturas, títulos e links dos vídeos originais.
3. Mostrar visualizações, curtidas, comentários e data de publicação, quando disponíveis.
4. Permitir que o usuário assista aos vídeos originais.
5. Procurar conteúdos semelhantes no Brasil.
6. Identificar possíveis oportunidades de conteúdo.
7. Permitir salvar vídeos interessantes em uma lista de favoritos.

## Regra principal

O sistema funciona no MODO ASSISTIDO.

Nenhum vídeo será enviado automaticamente para produção.

O usuário deverá assistir, analisar e aprovar cada oportunidade.

## Fontes planejadas

- YouTube Data API
- TikTok Creative Center
- Outras fontes públicas autorizadas

## Prioridade

Construir utilizando ferramentas gratuitas sempre que possível.
